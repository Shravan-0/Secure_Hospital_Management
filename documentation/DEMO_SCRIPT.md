# 10-minute demonstration script

**0:00–1:00 – Introduction**
“CareSecure is a small hospital management desktop application developed using Python, Tkinter and SQLite. The focus is not only hospital workflows but secure access to sensitive information.”

**1:00–2:00 – Roles**
Explain Admin, Doctor and Receptionist. Point out that each role sees only the relevant functions.

**2:00–4:00 – Admin**
Sign in as `admin`. Show overview, staff account list and security activity. Mention password hashes and role permissions.

**4:00–5:30 – Receptionist**
Sign out, sign in as `reception`. Register a fictional patient and schedule an appointment with the demo doctor.

**5:30–7:00 – Doctor**
Sign out, sign in as `doctor1`. Show assigned appointments and add a short fictional consultation note for an assigned patient.

**7:00–8:30 – Security demonstration**
As receptionist, point out that the medical-record menu is not available. Explain that permissions are checked in service functions as well as the interface.

**8:30–9:15 – Audit**
Return to admin and show login, patient creation and appointment creation events.

**9:15–10:00 – SELC mapping**
Summarize requirements, least privilege, defence in depth, STRIDE, testing and the basic DevSecOps workflow.

Use only fictional demo data. Do not enter real patient information.
